# WTR Lab Delulu Destroyer

Filter WTR Lab novels by genre, tag, and keyword with blocklist profiles and a floating UI.

## Installation

1. Install a userscript manager such as ScriptCat, Violentmonkey, Tampermonkey, or Stay.
2. Install the script from Greasy Fork: https://greasyfork.org/en/scripts/575938-wtr-lab-delulu-destroyer
3. Visit WTR Lab and refresh any already-open matching pages after installation.

## Current Version

- Package: `wtr-lab-delulu-destroyer`
- Version: `5.2.1`

## Usage

Open WTR Lab listing pages and confirm the filter panel opens and filtering still works.
